## 1. Responsibilities & Objectives

### 1. Image Encoder Backbone (Vision Transformer / ViT)
Per the selected base paper by **Khader et al. (2023)**, the **image encoder is a Vision Transformer (ViT)**, replacing any legacy convolutional (CNN) approach. It is responsible for processing chest X-ray images and converting them into numerical representations for multimodal fusion.

#### The ViT Workflow:
1. **Non-Overlapping Patch Partitioning**:
   - Divide each input chest X-ray image of size $H \times W$ (e.g., $224 \times 224$) into small, non-overlapping square patches of size $P \times P$ (e.g., $16 \times 16$).
   - The total number of patches is $N = \frac{HW}{P^2}$ (e.g., $14 \times 14 = 196$ patches for $224 \times 224$ images with $P=16$).
2. **Patch Conversion into Image Tokens**:
   - Flatten each patch and linearly project it into a $d_{\text{model}}$-dimensional vector space.
   - Each resulting vector serves as an **image token**, capturing visual information from that specific localized radiographic region.
3. **Positional Information**:
   - Add spatial positional information (learnable 1D or 2D positional embeddings) to the image tokens:
     $$z_0 = [\mathbf{x}_{\text{patch}}^1 \mathbf{E}; \dots; \mathbf{x}_{\text{patch}}^N \mathbf{E}] + \mathbf{E}_{\text{pos}}$$
   - This preserves the spatial arrangement and anatomical geometry of the chest cavity across patches.
4. **Transformer Layer Processing**:
   - Process the sequence of image tokens through standard Transformer encoder layers.
   - Each layer applies Multi-Head Self-Attention (MHSA), Multi-Layer Perceptrons (MLP / feedforward blocks), Layer Normalization, and residual connections to learn global and contextualized visual representations from the chest radiograph.
5. **Image Representation Generation for Multimodal Fusion**:
   - Produce output visual representations (either a pooled visual embedding vector $h_{\text{img}} \in \mathbb{R}^{d_{\text{img}}}$ or a sequence of contextualized visual tokens) and pass them to the multimodal fusion stage to be combined with clinical information.
6. **Explainability Support (Grad-CAM)**:
   - For downstream explainability analysis, the image-token representations generated by the Vision Transformer provide the foundation for Grad-CAM heatmaps to identify which specific anatomical regions of the chest X-ray contributed to a particular disease prediction.

#### Implementation & ViT Variant Guidelines:
- **Framework Support**: A suitable PyTorch / Torchvision ViT implementation (e.g., `torchvision.models.vision_transformer` / `torchvision.models.vit_*`) or `timm` may be used.
- **No Unapproved Assumptions**: The final selection of a specific ViT variant (e.g., `vit_b_16`, `vit_s_16`, a lightweight or mobile ViT, or custom transformer parameters) is an **open technical choice** pending team confirmation and memory benchmarking on target hardware. Do not hardcode an unapproved variant as final.
- **Configurable Dimensions**: Keep the vision embedding dimension ($d_{\text{img}}$ / $d_{\text{model}}$) parameterized so it can adapt to whichever variant the team confirms.

### 2. Multimodal Fusion Layer
- Design a fusion module that combines:
  - Visual representations $h_{\text{img}}$ (generated by your ViT Image Encoder)
  - Clinical representations $h_{\text{clin}}$ (generated by Member 4's Clinical Encoder)
- Note: In the base paper (Khader et al., 2023), multimodal fusion is performed by a Transformer encoder. For initial baseline integration, support a clean interface taking both representations with configurable feature dimensions (e.g., concatenation and projection block, or cross-attention/transformer blocks).
- Ensure the fusion module handles dimensions dynamically: $d_{\text{fused}} = d_{\text{img}} + d_{\text{clin}}$.

### 3. Binary Classification Head
- Final projection layer (Multi-Layer Perceptron / linear head) mapping fused multimodal features to a single unnormalized logit ($1$ output neuron).
- Binary objective:
  - Class 1 = `Pneumonia`
  - Class 0 = `Non-Pneumonia` (negative class can contain other non-pneumonia pathologies or no finding)
- Forward signature outputs logits suitable for `nn.BCEWithLogitsLoss`.

### 4. Integration with Member 4

- Run forward-pass unit tests with synthetic tensors to guarantee stability before full pipeline integration.

## 3. Step-by-Step Implementation Guide

### Step 1: Implement ViT Image Encoder & Fusion Classifier
Create `models/multimodal_net.py`:
```python
import torch
import torch.nn as nn
from torchvision import models

class ImageEncoder(nn.Module):
    """
    Vision Transformer (ViT) Image Encoder based on Khader et al. (2023).
    
    Workflow:
      1. Divides input chest X-ray [B, 3, 224, 224] into non-overlapping patches.
      2. Linearly projects patches to image tokens.
      3. Adds spatial positional embeddings to preserve anatomical layout.
      4. Passes tokens through Transformer encoder layers (self-attention + MLP).
      5. Yields image representations for multimodal fusion.
      
    Note: A suitable PyTorch/Torchvision ViT implementation is used below as a
    proposed choice (e.g. vit_b_16). The final ViT variant is subject to team approval.
    """
    def __init__(self, embed_dim=256, vit_variant="vit_b_16", pretrained=True):
        super().__init__()
        # Proposed implementation using torchvision.models ViT
        # Variant choice is configurable based on team confirmation
        if hasattr(models, vit_variant):
            vit_fn = getattr(models, vit_variant)
            weights = "DEFAULT" if pretrained else None
            try:
                self.vit = vit_fn(weights=weights)
            except Exception:
                self.vit = vit_fn(pretrained=pretrained)
        else:
            raise ValueError(f"Unsupported ViT variant: {vit_variant}")
            
        in_features = self.vit.heads.head.in_features
        # Replace classification head with projection to target embedding dimension
        self.vit.heads.head = nn.Linear(in_features, embed_dim)
        self.embed_dim = embed_dim
        
    def forward(self, x):
        # Input: [B, 3, 224, 224] -> Output: [B, embed_dim]
        return self.vit(x)


class FusionClassifier(nn.Module):
    """
    Multimodal Fusion and Binary Classification Head.
    Combines ViT visual representations and clinical representations.
    """
    def __init__(self, img_embed_dim=256, clin_embed_dim=64, hidden_dim=128, dropout_rate=0.3):
        super().__init__()
        fused_dim = img_embed_dim + clin_embed_dim
        
        self.fusion_block = nn.Sequential(
            nn.Linear(fused_dim, hidden_dim),
            nn.BatchNorm1d(hidden_dim),
            nn.ReLU(),
            nn.Dropout(p=dropout_rate)
        )
        # Binary classification output: 1 logit (Pneumonia vs Non-Pneumonia)
        self.head = nn.Linear(hidden_dim, 1)

    def forward(self, h_img, h_clin):
        # Concatenate visual and clinical representations along feature dimension
        h_fused = torch.cat([h_img, h_clin], dim=1)
        features = self.fusion_block(h_fused)
        logits = self.head(features)
        return logits


class MultimodalNet(nn.Module):
    """
    Assembled Multimodal Architecture combining:
      - Vision Transformer (ViT) Image Encoder
      - Clinical Encoder (Member 4)
      - Multimodal Fusion & Classification Head
    """
    def __init__(self, clinical_encoder_module, img_embed_dim=256, clin_embed_dim=64, vit_variant="vit_b_16"):
        super().__init__()
        self.image_encoder = ImageEncoder(embed_dim=img_embed_dim, vit_variant=vit_variant)
        self.clinical_encoder = clinical_encoder_module  # Provided by Member 4
        self.fusion_classifier = FusionClassifier(
            img_embed_dim=img_embed_dim,
            clin_embed_dim=clin_embed_dim
        )

    def forward(self, images, clinical_features):
        # Both pathways execute in parallel on their respective modalities
        h_img = self.image_encoder(images)
        h_clin = self.clinical_encoder(clinical_features)
        logits = self.fusion_classifier(h_img, h_clin)
        return logits
```

import torch
import torch.nn as nn
from models.multimodal_net import ImageEncoder, FusionClassifier, MultimodalNet

def test_vit_image_encoder():
    # Test with default proposed variant (without downloading large weights during unit test)
    encoder = ImageEncoder(embed_dim=256, pretrained=False)
    dummy_img = torch.randn(2, 3, 224, 224)
    h_img = encoder(dummy_img)
    assert h_img.shape == (2, 256), f"Expected (2, 256), got {h_img.shape}"
    print("[PASS] ViT ImageEncoder forward pass verified.")

def test_fusion_and_head():
    fusion = FusionClassifier(img_embed_dim=256, clin_embed_dim=64)
    h_img = torch.randn(4, 256)
    h_clin = torch.randn(4, 64)
    logits = fusion(h_img, h_clin)
    assert logits.shape == (4, 1), f"Expected (4, 1), got {logits.shape}"
    print("[PASS] FusionClassifier forward pass verified.")

def test_assembled_multimodal():
    # Mock clinical encoder for testing before Member 4 integrates
    mock_clinical_encoder = nn.Linear(3, 64)
    model = MultimodalNet(
        clinical_encoder_module=mock_clinical_encoder,
        img_embed_dim=256,
        clin_embed_dim=64
    )
    
    dummy_img = torch.randn(2, 3, 224, 224)
    dummy_clin = torch.randn(2, 3)
    logits = model(dummy_img, dummy_clin)
    assert logits.shape == (2, 1), f"Expected (2, 1), got {logits.shape}"
    print("[PASS] Complete MultimodalNet (ViT + Clinical) end-to-end forward pass verified.")

if __name__ == "__main__":
    test_vit_image_encoder()
    test_fusion_and_head()
    test_assembled_multimodal()
